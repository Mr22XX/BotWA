# WhatsApp Bot - Kirim Gambar Otomatis

Bot ini dibuat menggunakan [`@open-wa/wa-automate`](https://github.com/open-wa/wa-automate-nodejs) untuk mengirim gambar **buaya** atau **anjing** secara otomatis ketika pengguna mengirim perintah tertentu lewat WhatsApp.

## 📦 Fitur
-- Note : Kostumisasi saja Sesuai kebutuhan ini hanya contoh simple
- ✅ Kirim gambar buaya saat pengguna mengetik `gambar buaya`.
- ✅ Kirim gambar anjing saat pengguna mengetik `gambar anjing`.
- ✅ Menampilkan menu perintah saat pengguna mengetik `menu`.

## 🛠️ Instalasi

### 1. Clone Repositori

```bash
    git clone https://github.com/namauser/whatsapp-image-bot.git
    cd whatsapp-image-bot

```
### 2. Instal Dependensi & Run

     npm install
     node index.js
